# ✦ Pixium

**Pixium** is a modern, lightweight Windows utility for image conversion, resizing, compression, and PDF tools — designed to make everyday file processing fast, simple, and private.

## ✨ Features

- 🖼️ Image resizing
- 🔄 Image format conversion
- 📦 Image compression
- 📄 Image to PDF
- 🖱️ Drag & drop support
- 🔒 Offline/local file processing
- 🎨 Modern dark UI with a purple accent theme
- ⚡ Lightweight Windows desktop application

## 🎯 What Pixium Can Do

Pixium is designed for common image and document tasks such as:

- Resize images to an exact pixel size
- Increase or reduce image dimensions
- Compress images to reduce file size
- Convert between supported image formats
- Convert images into PDF documents
- Prepare images for websites, applications, forms, and documents
